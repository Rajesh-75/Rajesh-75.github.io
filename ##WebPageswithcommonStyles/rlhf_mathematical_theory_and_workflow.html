Reinforcement Learning from Human Feedback (RLHF): Mathematical Theory & Steps

RLHF is a training paradigm used to align Large Language Models (LLMs) with human preferences, ensuring outputs are helpful, honest, and harmless. The process bridges supervised pre-training with human-guided optimization.

1. The Core Steps Involved in RLHF

The standard RLHF pipeline consists of three distinct phases:

Phase 1: Supervised Fine-Tuning (SFT)

The base LLM is fine-tuned on a curated dataset of high-quality prompt-response pairs to learn the formatting and styling expectations of an assistant.

What are the Formatting and Styling Expectations of an Assistant?

Before fine-tuning, a base model only knows how to complete text. SFT teaches the model a conversational contract:

  • The Persona: Maintaining a neutral, helpful, and polite tone.
  • Directness: Directly addressing the user's prompt without rambling or random trailing thoughts.
  • Structural Clarity: Using markdown, bullet points, and code blocks when appropriate.
  • Safety & Refusal Boundaries: Knowing how to politely decline harmful or unethical requests.

Example 1 (Coding & Structure)

Prompt: "Write a Python snippet to check if a number is prime and explain how it works."

def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

Explanation: This function checks divisibility up to the square root of $n$, making it computationally efficient ($O(\sqrt{n})$).

Phase 2: Reward Model (RM) Training

A separate model is trained to score responses based on human preferences, acting as a proxy for human judgment.

Phase 3: RL Optimization (PPO)

The SFT model is optimized as a policy using Proximal Policy Optimization, where the reward signal comes from the Reward Model.

2. Mathematical Theory of RLHF

Phase 2: The Reward Model (Bradley-Terry Model)

Human preference data usually comes in pairs: given a prompt $x$, a human prefers response $y_w$ (winning) over response $y_l$ (losing).

We model the probability using the Bradley-Terry pairwise comparison model:

$$P(y_w \succ y_l \mid x) = \sigma(r_\theta(x, y_w) - r_\theta(x, y_l))$$

Where $r_\theta(x, y)$ is a scalar score outputted by the Reward Model parameterized by $\theta$, and $\sigma(z) = \frac{1}{1 + e^{-z}}$ is the logistic sigmoid function.

The Loss Function minimized over dataset $\mathcal{D}$:

$$\mathcal{L}(\theta) = - \mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}} \left[ \log \sigma(r_\theta(x, y_w) - r_\theta(x, y_l)) \right]$$

Phase 3: The RL Policy Optimization Objective

The goal is to maximize expected reward while preventing the model from drifting away from the original SFT model $\pi_{SFT}$:

$$\max_{\phi} \mathbb{E}_{x \sim D, y \sim \pi_\phi(y \mid x)} \left[ r_\theta(x, y) \right] - \beta \, D_{KL}\left( \pi_\phi(y \mid x) \,\vert{}\vert{}\, \pi_{SFT}(y \mid x) \right)$$
  • Expected Reward: Encourages generating responses that score high according to human preference.
  • KL-Divergence Penalty: Measures deviation from the reference SFT model, controlled by hyperparameter $\beta$, preventing reward hacking.
