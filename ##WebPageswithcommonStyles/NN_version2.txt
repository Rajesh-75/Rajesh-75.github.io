<h2>Neural Networks</h2>

<div class="description-box">
    <h3>The Architecture of Intelligence</h3>
    <p>
        A Neural Network is a powerful Machine Learning model designed to identify complex patterns in data. 
        It is the foundational technology behind modern AI, widely used for <strong>Pattern Recognition</strong> (such as identifying objects in photos), 
        <strong>Image Generation</strong>, and <strong>Natural Language Processing</strong> (like predicting the next word in a sentence).
    </p>
    <p>
        A Neural Network is one of the few Machine Learning models capable of handling massive amounts of high-dimensional data, 
        such as millions of pixels in an image or billions of tokens in text. Modern Neural Networks are significantly larger than early AI models, both in terms of 
        <strong>learnable parameters</strong> (the weights) and the <strong>depth of internal processing</strong> (the number of hidden layers).
    </p>
    <p> 
        Modern Neural Networks require massive computational infrastructure. Training these models on a standard CPU (Central Processing Unit) would take years because CPUs are designed for general-purpose tasks. Instead, modern AI relies on GPUs (Graphics Processing Units) and specialized chips like TPUs (Tensor Processing Units). These processors are built for massive parallelism, allowing them to perform thousands of mathematical calculations simultaneously.
    </p>
</div>

<div class="description-box">
    <h3>From Linear Regression to Stacks of Logistic Units</h3>
    <p>
        Linear and Logistic Regression, as seen in earlier chapters, take inputs, multiply them by weights, and produce an output. 
        A Neural Network is a "multi-layer" stack of linear and logistic regression units. This multi-layer structure allows the model to process data in stages, where each layer leads to the creation of new <strong>features</strong>.
    </p>

    <div class="formula-box" style="text-align: center; margin: 20px 0; background: #f8fafc; padding: 15px; border-radius: 8px;">
        $$n_1^{(2)} = \sigma\left(W_{11}^{(1)}n_1^{(1)} + b_1^{(2)}\right), \qquad n_1^{(3)} = \sigma\left(W_{11}^{(2)}n_1^{(2)} + b_1^{(3)}\right)$$
    </div>

<div class="description-box" style="border-left: 5px solid #3182ce;">
    <h3>The Learning Cycle</h3>
    <p>Training a Neural Network broadly involves four distinct phases. We will explore the mechanics of each phase in the following sections:</p>
    <ol class="process-list">
        <li><strong>Forward Pass:</strong> Data is fed through the network to generate predictions (detailed in Sections 1-4).</li>
        <li><strong>Loss Calculation:</strong> A function measures how far off the predictions were from the true labels (Section 5).</li>
        <li><strong>Backpropagation:</strong> The error is propagated backward to compute gradients.</li>
        <li><strong>Weight Update:</strong> An optimizer (like Adam) uses gradients to update weights.</li>
    </ol>
</div>

<div class="tutorial-content">
    <ul>
        <li class="section-item">
            <span class="section-title">1. The Inputs (Layer L=0): The Feature Vector</span>
            <p>The first layer is where your "raw features" live. Each neuron ($n_1, n_2, n_3$) represents a measurable attribute, like "Tail Length" or "Whiskers" in a cat classifier. These are the only values grounded in direct reality before the abstraction begins.</p>
        </li>

        <li class="section-item">
            <span class="section-title">2. The Weights ($W_{jk}^{(l)}$): Trust and Influence</span>
            <p>Weights represent the "influence" one neuron has on the next. A positive weight is a vote of confidence, while a negative weight acts as a "veto."</p>
        </li>

        <li class="section-item">
            <span class="section-title">3. The Weighted Sum: The Linear Core</span>
            <p>Before the activation happens, each neuron performs a linear regression step, accumulating incoming signals plus a <strong>Bias ($b$)</strong> which acts as the intercept:</p>
            <div class="math-display">
                $$z_j^{(l)} = \sum_{k} (w_{jk}^{(l-1)} \cdot n_k^{(l-1)}) + b_j^{(l)}$$
            </div>
        </li>

        <li class="section-item">
            <span class="section-title">4. The Activation Function: The Non-Linear Step</span>
            <p>By using functions like <strong>ReLU</strong> or <strong>Sigmoid</strong>, we allow the network to "bend" the rules, enabling it to learn relationships that aren't just straight lines. These hidden layers automatically combine raw inputs into high-level features.</p>
        </li>

        <li class="section-item">
            <span class="section-title">5. The Verdict: Softmax and Loss</span>
            <p>The final layer scores are squashed by a <strong>Softmax Layer</strong> to produce probabilities. If the network predicts "90% Cat" when the truth is "Dog," the <strong>Loss Function</strong> (like Cross-Entropy) generates a penalty that guides the next update.</p>
        </li>
    </ul>
</div>

<div class="description-box">
    <h3>Mathematical Deep Dives</h3>
    
    <div class="section-item">
        <span class="section-title">The Calculus of ReLU: Why the Gradient is 1</span>
        <p>For all values where $z > 0$, ReLU acts as the identity function ($f(z) = z$), meaning its derivative is exactly 1. This allows the "error signal" to pass through the neuron unchanged during training, though if $z < 0$, the gradient becomes 0—a state known as the "Dying ReLU" problem.</p>
    </div>

    <div style="border-left: 5px solid #2ecc71; background: #f0fff4; padding: 20px; border-radius: 8px; margin: 20px 0;">
        <h4 style="margin-top: 0; color: #27ae60;">Architectural Math: Parameter Counting</h4>
        <p>To calculate the complexity of a Dense Layer, we multiply the input dimension by the output dimension.</p>
        <div style="background: white; padding: 10px; border: 1px dashed #27ae60; font-family: monospace;">
            Input Size ($L_1$): n <br>
            Output Size ($L_2$): n - 4 <br>
            -------------------------- <br>
            <strong>Connection Count:</strong> n * (n - 4) = n² - 4n
        </div>
        <p style="font-size: 0.85rem; margin-top: 15px;">
            <em>Note:</em> In Large Language Models, $n$ is often 4096 or higher, leading to millions of connections per layer.
        </p>
    </div>
