• 6. The Parameterized Loss Landscape (3D Visualization)
    [3D Surface Plot: $w_1$ (X), $w_2$ (Y), and Loss (Z)]

    The surface represents the function $L(w_1, w_2)$. Training is the process of navigating this non-convex "terrain" to find the global minimum.

    As noted by Bishop, the loss function $f(y_i, t_i; w_i)$ creates a non-convex surface. In this 3D projection:

    • Axes $x, y$: Represent the weights $w_1$ and $w_2$ of the neurons.
    • Axis $z$: Represents the value $y$ (Loss/Error).
    • Local Minima: The "valleys" where the model can get stuck if the learning rate is not optimized.
    Architect's Tip: Modern models have billions of weights, creating a "high-dimensional" landscape that we cannot visualize, but the same mathematical principles of Gradient Descent apply.
