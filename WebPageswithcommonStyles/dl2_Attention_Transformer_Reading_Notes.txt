The Attention Context Vector: A Custom-Made BlendThe diagram you shared reveals how the attention mechanism completely eliminates this bottleneck. Instead of forcing one hidden state to memorize everything, the Transformer keeps all intermediate token vectors in memory as Keys and Values.How it is built: When the model needs to generate the next word, it emits a Query ($\mathbf{q}$). This query looks at all the words simultaneously, calculates the scalar attention weights ($\alpha$), and performs a weighted sum of the Values ($\mathbf{v}_i$).The Result (Dynamic Flexibility): The output of this calculation is also called the Context Vector. But unlike the static RNN bottleneck, this Context Vector is dynamically custom-built on the fly for that exact moment.If the decoder is trying to translate a specific noun 40 words back, the query can instantly allocate $95\%$ of the attention weight to that exact word's Value vector, creating a Context Vector that perfectly preserves the original meaning without any memory loss.
